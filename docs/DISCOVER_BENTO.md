# Discover visual browsing

Discover Posts uses controlled Bento groups of three: a tall left tile with two stacked right tiles, the mirror arrangement, then a wide tile above two smaller tiles. Groups repeat in existing result order. Layout position adds no popularity, creator, paid or quality weighting. Filtering recomputes this rhythm from the filtered results; ordinary browsing never randomly rearranges items.

The final one or two items use a full-width tile or equal pair, so partial groups leave no empty slots. Gutters are 10px and corners 16px. Fixed group dimensions reserve space before lazy images load. No masonry measurement, dependency or network request is added.

The main image uses contain to preserve the entire professional frame. A softly blurred decorative copy fills unused space behind it. Both use the same URL and browser cache; the background is hidden from assistive technology. Small video/set markers remain. Text-only search results retain readable note tiles.

Existing result IDs and selected index pass directly to the vertical post stream. Back restores the mounted Discover surface; images in the stream do not open another lightbox. Each tile retains its labelled keyboard button and list semantics, including when visual placement mirrors the layout.

People, Opportunities, Events, Reviews, structured Projects, Saved posts and the profile sections below the immersive hero retain their existing layouts and behavior. Portfolio and project imagery shared as posts participates in Bento; this task creates no additional content collection or permissions.
