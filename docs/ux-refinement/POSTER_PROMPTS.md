# Poster prompts

Prompts for the six missing posters (`POSTER_INVENTORY.md`), to be generated outside the app.

**Rights.** These films are fictional, so the posters are commissioned prototype artwork. The product owner approved this on 2026-10-08, which amends D4 for the prototype only. For real productions, D4 still applies: use only the production's own poster.

**Wiring.**

1. Save each image as `public/images/posters/<project id>.jpg`.
2. Add the id to `SUPPLIED` in `src/data/posters.ts`.

## Shared ending

Add this to every prompt:

> Vertical 2:3 portrait (1024×1536), a theatrical one-sheet. Photographic, cinematic lighting, subtle 35mm film grain, Indian setting. Leave clear space for the title. The only text on the poster is the title given above, spelled exactly; no credits block, tagline, logos, dates or watermark. Original characters only; they must not resemble any real actor.
