# Person photos (prototype fixtures)

`{personId}.jpg` is that person's canonical profile photo. Seeded people point here by default
(`photo` in `src/data/seed.ts`); a missing file falls back to initials.

The four files here (kiran, tara, meera, vikram) are prototype fixtures cropped from the project's
own generated, fictional stills (see docs/IMAGE_PROMPTS.md) so the portrait-led cards can be
evaluated. They are not real people. Replace them with the commissioned portraits from the brief.
People created in onboarding use the photo they pick there.
